Vendor statement upload template

Share this template with your vendor. They fill in one row per open invoice and send it back. You then upload the completed file on the Vendor Data page to reconcile it against SAP.

Required columns

ColumnRequiredDescription / Example
Invoice NoYesThe vendor's invoice number, e.g. 081/EXT/2026
AmountYesInvoice amount, e.g. 53.45 (commas and currency symbols are handled)
Invoice DateOptionalFormat dd-mm-yyyy, e.g. 17-03-2026
CurrencyOptionale.g. USD

Column names are flexible — the parser also recognises common aliases like "Invoice Number", "Bill No", "Value", "Debit", "Date". Invoice No and Amount must be present.

Transaction ledger template (full ledger)

For Transaction Reconciliation. The vendor lists every transaction for the period — opening balance, invoices, payments, credit/debit notes, and closing balance.

Columns

ColumnRequiredDescription / Example
DateRecommendedFormat dd-mm-yyyy, e.g. 05-03-2026
Transaction TypeYesOpening Balance, Invoice, Payment, Credit Note, Debit Note, Closing Balance
Reference NoRecommendedInvoice / payment / document number, e.g. 081/EXT/2026
DebitYes*Increases payable (invoices, debit notes), e.g. 53.45
CreditYes*Decreases payable (payments, credit notes), e.g. 5000.00
CurrencyOptionale.g. USD
NarrationOptionalFree text remarks

*Provide Debit and Credit columns (a single signed Amount column also works: positive = debit, negative = credit). Opening/Closing balance go in the Debit column as a single figure.
